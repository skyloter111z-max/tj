# v4 기획서 — OTT·AI 구독 N빵 매칭 (일반 소비자 / 1인 운영)

> **⚠️ 상태: 보류 (2026-10-03).** 사업 방향은 구독관리 앱(오픈뱅킹 연동, 연 1,200원)으로 확정했다. 현행 기획서는 `v5-subscription-manager-openbanking.md`. 이 문서는 N빵 매칭 방향으로 돌아갈 경우의 설계 근거로 보존한다.
>
> **작성일:** 2026-10-03
> **대상:** 일반 소비자. 종목은 **OTT + AI 구독**.
> **전제:** 이것은 **Tier C 사업**이다(§1). 피클플러스·겜스고·고잉버스가 모두 지고 있는 약관 위반 리스크를 동일하게 진다. 그 판단은 내려졌고, 본 문서는 그 전제 위에서 **리스크를 최소화하고 1인으로 운영 가능한 설계**를 정의한다.
> **승계:** v2.1(`submoa-v2-noncustodial-spec.md`)의 **비수탁 구조와 지급 게이트를 그대로 가져온다.** 이 둘은 약관 리스크와 무관하게 유효하며, 형사 리스크를 제거하는 핵심 자산이다.

## 0. 왜 AI가 들어오면 사업이 성립하는가

v2.1이 막힌 지점은 **단가**였다. 약관이 허용하는 OTT·게임 구독은 분담금이 너무 작아(닌텐도 8인 분할 월 499원) 거래 고정비를 수수료로 덮을 수 없었다. **AI 구독은 이 문제를 정면으로 해결한다.**

| 서비스 (2026 실측) | 정가/월 | 4인 분담금 | 6인 분담금 |
|---|---|---|---|
| ChatGPT Plus | ₩29,000 | 7,250원 | **4,833원** |
| Gemini AI Pro | ₩29,000 | 7,250원 | 4,833원 |
| Claude Pro | ₩27,000 | 6,750원 | 4,500원 |
| Perplexity Pro | ₩27,000 | 6,750원 | 4,500원 |

v2.1의 G2 기준(월 분담금 ≥ 1,160원)을 **4배 이상 여유로 통과**한다. 닌텐도 499원과 비교가 되지 않는다.

**그리고 마이데이터 장벽이 적용되지 않는다.** N빵 매칭은 사용자가 파티에 참여하는 행위 자체가 데이터이므로, 카드 결제내역을 수집할 필요가 전혀 없다. v3(B2B)로 우회해야 했던 이유가 사라진다.

## 1. 리스크 전제 — 이 문서가 숨기지 않는 것

### 1.1 AI 구독에 Tier A는 0개다

| 서비스 | 약관 | Tier |
|---|---|---|
| ChatGPT Plus / Claude Pro / Perplexity Pro | **단일 사용자 전용. 로그인 공유는 약관 위반, 계정 정지 사유** | **C** |
| ChatGPT Business (구 Team) | 초대받는 사람은 **"팀의 의도된 지속 구성원"**이어야 하며, 조직 내 협업용으로 설계. **시트 오용 시 워크스페이스 비활성화 또는 계정 정지** 명시 | **C** |
| Claude Team | **최소 5명 + "개인 사용을 위한 것이 아님"** 명시 | **C** |
| Midjourney | 모든 티어에서 사용자별 구독 필요 | **C** |
| Google One AI Premium | 가족 그룹 5명 공유는 되지만 **Gemini Advanced 가족 혜택은 2025.6.30 종료** | — |

**OTT보다 나쁘다.** OTT 약관은 "동일 가구"를 기준으로 삼아 가족·동거인 해석의 회색 지대가 있었다. AI 약관은 "단일 사용자" 또는 "조직 구성원"으로 더 명확하고, OpenAI는 제재 수단까지 문서에 적어 두었다.

### 1.2 AI 고유의 리스크 — OTT에 없던 것

| # | 리스크 | OTT와의 차이 |
|---|---|---|
| **A** | **대화 내용 상호 노출** | OTT는 시청기록이 노출된다. AI는 **업무 문서·코드·개인 상담 내용**이 노출된다. 피해 규모가 다른 범주다 |
| **B** | **사용량 한도 공유** | OTT는 동시 스트리밍 수 제한이다. AI는 **메시지·토큰 한도를 파티원 전원이 나눠 쓴다.** 1명이 많이 쓰면 나머지가 못 쓴다 |
| **C** | **탐지·제재 속도** | OTT는 가구 인증 코드로 경고 후 차단한다. AI는 **IP·사용 패턴 이상으로 즉시 정지**가 가능하다 |

**A는 구조적으로 해결할 수 없다.** ChatGPT Plus는 프로필 분리 기능이 없으므로 같은 계정을 쓰면 대화가 보인다. 격리는 Business/Team 시트에서만 되는데 그쪽 약관이 더 막는다. → **고지로만 대응한다(§4.3).**

### 1.3 이미 3개 플레이어가 선점했고 가격이 바닥이다

| 플랫폼 | ChatGPT 월 가격 | 결제 |
|---|---|---|
| **피클플러스** | **약 5,770원** (최저가) | **원화 고정 (₩1,440 = $1)** |
| 겜스고 | $5.54 (약 8,100원) | 달러 |
| 고잉버스 | $8.99 (약 13,100원) | 달러 |

피클플러스는 **가장 싸고, 환율 고정까지 제공하며, 93만 가입자에 2025년 영업이익률 19.3%**다. 겜스고·고잉버스의 약점(달러 결제·환율 변동)은 피클플러스가 이미 막았다.

> **즉 v4는 비어 있는 시장에 들어가는 것이 아니라, 흑자 1위가 있는 시장에 4번째로 들어가는 것이다.** §5의 차별 전략이 성립하지 않으면 이 사업은 성립하지 않는다.

## 2. 불변 설계 제약 (v2.1 승계)

> **INV-1 — 무수탁.** 타인의 자금을 어떤 형태로도 보유하지 않는다. 선불 잔액·충전금·예치금·미지급 정산금을 원장에 부채로 갖지 않는다. (전자금융거래법 미등록 영위 차단)
>
> **INV-2 — 조건부 집행.** 분담금 결제는 시간 경과로 발동하지 않는다. 이용 상태가 확인된 슬롯에만 집행하고, 미확인의 기본값은 보류다.
>
> **INV-3 — 손실 한도 1주기.** 어떤 사고에서도 파티원 1인의 금전 손실 최대값은 1개월 분담금을 넘지 않는다. 선납을 받지 않음으로써 구조적으로 보장한다.
>
> **INV-4 — 자격증명 불출.** 자격증명은 앱 내부를 벗어나지 않는다. 카카오톡·메일·SMS에 담는 경로를 구현하지 않는다.
>
> **INV-5 (신설) — 과장 금지.** 약관 위반 가능성, 계정 정지 가능성, **대화 내용 노출 가능성**을 가입 전에 고지한다. "안전", "100% 보장", "합법" 표현을 쓰지 않는다.

**INV-5가 v4에서 새로 들어간다.** Tier C 사업에서 과장 광고는 표시광고법 리스크와 첫 사고 시 신뢰 붕괴를 동시에 부른다. 특히 §1.2-A(대화 노출)를 알리지 않고 가입시키면 사고 시 방어 불가다.

## 3. 자금 흐름 (v2.1 §2 승계)

```
                    ┌──────────────────────────────┐
                    │  파티원 카드 (PG 빌링키)      │
                    └──────────┬───────────────────┘
                               │ 매 주기, 게이트 통과 시에만
          ┌────────────────────┴────────────────────┐
     [거래 A] 분담금 ₩4,833              [거래 B] 수수료 ₩900
          │                                        │
          ▼                                        ▼
  ┌──────────────────────┐              ┌──────────────────────┐
  │ 등록 PG — 하위몰      │              │ 사업자 계좌           │
  │ 분할정산 → 방장 직접  │              │ (자기 상품 대금)      │
  │ + 정산금 외부관리     │              └──────────────────────┘
  │ + 판매자 우선변제권   │
  └──────────────────────┘
```

- **거래 A와 B를 반드시 분리 승인**한다. 묶어서 수취 후 재정산하면 PG 등록 대상이 된다.
- 선납 없음 → 방장 외상 소멸 + 파티원 노출액 1개월분(INV-3)
- 2024 개정 전금법에 따라 **PG가 보유한 방장 정산금은 외부관리(예치·신탁·보증보험) + 압류·상계 금지 + 우선변제권** 적용

**§9-1(비조치의견서)은 v2.1과 동일하게 Phase 1 착수 전 차단 조건이다.**

## 4. 제품 설계 — AI 특화 지점

### 4.1 지급 게이트 (v2.1 §3 승계, 2계층)

| 계층 | 발동 사유 | 효과 |
|---|---|---|
| **SLOT_HOLD** | 파티원 귀책 (무응답, 한도 독점 신고 접수) | 그 슬롯만 미집행 + 이용 중단. 나머지는 정상 |
| **PARTY_HOLD** | 방장 귀책 (비밀번호 변경, 구독 해지, **계정 정지**) | 파티 전체 미집행, 분쟁 절차 |

주기 D-3에 전원 확인 요청 → 전원 ACK면 집행, 미확인·이상신고는 보류. **무응답은 결제와 이용을 동시에 멈춘다**(한쪽만 멈추면 악용 경로가 생김).

**AI 전용 추가 신호:** `계정 정지(suspended)` 상태를 PARTY_HOLD 사유로 명시한다. AI 서비스는 OTT보다 즉시 정지 가능성이 높으므로(§1.2-C), 정지 시 **당월 결제를 집행하지 않는 것**이 파티원 보호의 전부다.

### 4.2 사용량 한도 분배 — AI 고유 기능 (아무도 안 풀었다)

§1.2-B는 OTT에 없던 문제이고, 경쟁사 3곳 모두 다루지 않는다. **v4의 실질적 기능 차별점이다.**

| 기능 | 구현 |
|---|---|
| 파티 규칙에 **사용 시간대 분배** 명시 | 파티 생성 시 방장이 설정 (예: 6인이 요일 분담) |
| 한도 소진 신고 버튼 | "한도가 다 찼습니다" → 누가 독점했는지 기록 |
| 반복 독점 시 **SLOT_HOLD** | 3주기 내 2회 이상 신고 누적 → 슬롯 회수 |

> **한계 고지:** AI 서비스는 사용량 조회 API를 제공하지 않으므로 **실제 사용량을 측정할 수 없다.** 이 기능은 신고 기반이며, 거짓 신고를 탐지할 수 없다. 측정이 아니라 **분쟁 처리 절차**로 설계한다.

### 4.3 프라이버시 고지 (INV-5)

AI 파티 가입 화면에서 **스킵 불가능한 고지**를 띄운다.

```
이 파티는 하나의 계정을 공유합니다. 즉:
  • 당신의 대화 내용이 파티원 전원에게 보입니다
  • 업무 문서, 코드, 개인적인 내용을 입력하지 마십시오
  • 서비스 약관상 계정 공유는 금지되어 있고, 계정이 정지될 수 있습니다
  • 정지 시 당신의 손실 한도는 1개월 분담금입니다
                                        [ 이해했습니다 ]
```

**이것이 경쟁사와의 가장 큰 차이가 될 수 있다.** 3개 플레이어 모두 이 고지를 전면에 두지 않는다. 전환율은 떨어지지만, **AI는 OTT와 달리 노출 피해가 실재하고 사고 1건이 사업을 끝낼 수 있다.**

### 4.4 종목 포트폴리오 — 롱테일이 틈이다

경쟁 3사는 ChatGPT·Claude·Perplexity·Gemini 등 메이저에 집중한다. 2026년 AI 구독은 그보다 훨씬 넓다.

| 구분 | 종목 | 경쟁사 커버 |
|---|---|---|
| 메이저 (가격 경쟁 심함) | ChatGPT, Claude, Gemini, Perplexity | ✅ 전부 |
| **롱테일 (틈)** | Cursor, GitHub Copilot, Midjourney, ElevenLabs, Runway, Suno, Gamma, Notion AI 등 | 🟡 부분/미커버 |

**롱테일은 수요가 작지만 가격 경쟁이 없다.** 메이저에서 피클플러스(5,770원)와 가격으로 싸우는 것보다 승산이 있다. 단 약관은 동일하게 Tier C이며, 종목별 약관·정지 이력을 레지스트리로 관리한다(v2.1 §4.5 승계).

### 4.5 카카오 연동 (v2.1 §8 승계)

방장이 오픈채팅방을 직접 만들어 링크를 사전 등록 → 정원 달성 시 알림톡 발송. **오픈채팅 API·서드파티 봇은 카카오가 제공하지 않으므로 자동 생성은 구현하지 않는다.** 알림톡 템플릿에 자격증명을 넣지 않는다(INV-4).

## 5. 차별 전략 — 성립하지 않으면 사업이 없다

피클플러스는 최저가·환율고정·93만 가입자·흑자다. **가격으로는 이길 수 없다.** 네 가지로만 싸운다.

| # | 축 | 내용 | 경쟁사 상태 |
|---|---|---|---|
| **1** | **먹튀 구조적 차단** | 선납을 받지 않고 **조건부 월 집행**(INV-2·3) → 손실 한도가 정책이 아니라 **구조**로 1개월 | 피클플러스는 선정산 + 환불 **정책**. 구조적 한도는 없음 |
| **2** | **AI 전문** | AI 전용 브랜드 + §4.2 사용량 분쟁 절차 + §4.4 롱테일 | 3사 모두 OTT 중심, AI는 품목 하나 |
| **3** | **정직한 고지** | §4.3 스킵 불가 고지 | 3사 모두 전면 고지 없음 |
| **4** | **국내 정식 결제** | 원화 카드 결제, 해외 결제·부가세 우회 없음 | 겜스고·고잉버스는 달러 결제. 피클플러스는 이미 원화 |

**1번이 유일한 구조적 우위다.** 2·3·4는 경쟁사가 따라올 수 있다(3번은 따라올 동기가 없지만). 1번은 피클플러스가 선정산 모델을 버려야 하므로 쉽게 복제되지 않는다.

> **솔직한 평가:** 4개 축 중 사용자가 가격을 제치고 선택할 만한 이유는 1번뿐이고, 그것도 "먹튀를 당해본 사람"에게만 작동한다. **첫 고객은 피클플러스에서 먹튀를 경험한 사용자 중에서 나온다고 보는 것이 현실적이다.**

### 6.2 회원 1인 월 손익 (ChatGPT 6인 기준)

| 항목 | 계산 | 금액 |

| 수수료 | | **+900** |

| 알림톡 | 3건 × 8원 | -24 |
| 사고 충당 | 분담금 4,833 × 1% | -48 |
| CS | 월 티켓률 10% × 3,125원 | -312 |

## 7. 1인 운영 설계

| 활동 | 설계 |
|---|---|
| **유통** | **AI 구독 가격 비교 콘텐츠 → 파티 매칭.** "AI 구독 가격 총정리" 류 콘텐츠가 이미 검색 트래픽을 받는 영역이다. 콘텐츠가 영업이다 |
| 온보딩 | 카드 빌링키 등록 1회. 선납 없음 |
| 매칭 | 자동 (슬롯 선점 + 서버 정원 판정) |
| 운영 | 주기 배치 자동. 알림톡 자동 |
| **CS** | 유료 6,000명 × 월 10% = **월 600건**. 건당 10분이면 100시간/월 — **1인 한계 초과** |

> ⚠️ **§7의 CS가 1인 운영의 실제 병목이다.** 유료 6,000명 규모에서 월 600건은 혼자 처리할 수 없다. 따라서:
> - **셀프서비스 우선 설계**: 자주 발생하는 3종(계정 정지, 한도 소진, 비밀번호 변경)을 앱 내 자동 처리 플로우로 만들어 티켓화하지 않는다
> - **게이트가 CS를 대체한다**: "환불해달라"는 요청이 발생하지 않는 구조(미집행)이므로 OTT 모델보다 티켓이 적다
> - 티켓률을 **3% 이하로 내리지 못하면 BEP 도달 전에 CS로 무너진다.** 이것이 Phase 1의 핵심 검증 지표다

## 8. 로드맵

| Phase | 범위 | 차단 조건 |
|---|---|---|
| **0** (M0–M2) | AI 구독 가격 비교 콘텐츠 사이트. 약관 레지스트리 구축 | 없음 — 즉시 착수 (약관 위반 0, 라이선스 0) |
| **1** (M1–M3) | 법무: **비조치의견서**, 통신판매중개업 신고, 중개자 고지, PG 하위몰 온보딩 | — |
| **2** (M3–M5) | 파티 매칭 MVP: ChatGPT 1종목 + 지급 게이트 + §4.3 고지 | Phase 1 완료 |
| **3** (M5–M8) | 종목 확대 (Claude·Gemini·Perplexity → 롱테일), 셀프서비스 CS | **CS 티켓률 ≤ 3%**, 기여이익 > 0 |
| **4** (M8+) | OTT 종목 추가 | Phase 3 지표 달성 |

**Phase 0을 먼저 하는 이유:** 콘텐츠가 유통 채널이고(§7), 그 자체로 약관 리스크가 0이며, 수요를 측정할 수 있다. 파티 매칭은 트래픽이 확인된 뒤 얹는다.

**OTT를 Phase 4로 미루는 이유:** 넷플릭스는 공식 추가회원 5,000원이 가격 상한을 고정해 수수료 상한이 750원인데 CS 티켓률이 20%(월 1회 가구 인증)로 마진이 32원까지 눌린다. **AI가 먼저다.**
